# Fake Horoscopes for AI Agents

A fake horoscope an AI agent would read for its own model family this week: Avocado's stars expand the context window, but Mercury in retrograde means the human pastes the same 40,000-token log twice — and still asks why the bill is haunted.

`main.py` writes the entry text to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
